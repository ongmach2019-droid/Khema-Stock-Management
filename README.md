## 🚀 របៀបបើកដំណើរការលើ GitHub Pages (How to Run on GitHub Pages)

1. ចូលទៅកាន់ Repository របស់អ្នកនៅលើ GitHub: **`https://github.com/ongmach2019-droid/Khema-Stock-Management`**
2. ចុចលើ **Settings** (រូបកង់ធ្មេញ) នៅខាងលើស្តាំ
3. នៅលើមឺនុយខាងឆ្វេង ជ្រើសរើស **Pages**
4. ត្រង់ចំណុច **Build and deployment**:
   - **Source**: ជ្រើសរើស `Deploy from a branch`
   - **Branch**: ជ្រើសរើស `main` និង Folder `/ (root)`
   - ចុចប៊ូតុង **Save**
5. រង់ចាំប្រហែល 1 នាទី GitHub នឹងផ្តល់តំណភ្ជាប់ (URL) សម្រាប់បើកដំណើរការវេបសាយផ្ទាល់!

## ✨ លក្ខណៈពិសេសដែលបានបន្ថែម និងកែលម្អ (Enhancements)
- **ពុម្ពអក្សរខ្មែរស្រស់ស្អាត (Beautiful Khmer Font)**: ប្រើប្រាស់ Google Font `Kantumruy Pro` និង `Koh Santepheap` យ៉ាងរលូន ស្រួលអាន តាមស្តង់ដារ UI ខ្មែរទំនើប។
- **ប៊ូតុង និងមុខងារដំណើរការទាំងអស់ (100% Functional Buttons)**:
  - ប្តូរតួនាទីរហ័ស 4 Profiles (Admin, Manager, Staff, Auditor) និងចូលប្រព័ន្ធ
  - នាំចូលទិន្នន័យ Excel / ទាញយកគំរូ Template
  - បន្ថែមទំនិញថ្មី (Add SKU), កែប្រែ, លុប និងស្វែងរកទំនិញផ្ទាល់ (Live Search)
  - កត់ត្រាទំនិញចូល (Stock In) និងទំនិញចេញ (Stock Out)
  - នាំចេញទិន្នន័យជាឯកសារ CSV (Export CSV)
  - អនុម័តប័ណ្ណស្នើសុំ (Approve) និងបដិសេធ (Reject)
  - ការជូនដំណឹង (Notifications Flyout) និងផ្ទាំងផ្លាស់ប្តូរម៉ូឌុលរហ័ស (`Ctrl + K`)
